Queue Management System for College Services Using Java

A Java-based application designed to organize queues for college services, issue tokens to students, and help staff manage student service requests efficiently.

Project Overview

The Queue Management System helps reduce physical queues and makes student service management more organized.

Key Features

- Student registration and login
- Token generation for different college services
- Separate queues for Office, Library, Fees Section, Certificates, and Administration
- Queue position and estimated waiting time
- Staff controls to call the next token, complete service, or skip a token
- Priority token management
- Now Serving display board
- Daily queue statistics

Technologies Used

- Java
- Java Swing
- Java NIO file handling
- SHA-256 password hashing
- Eclipse IDE

Project Files

- "QueueManagementSystem.zip" — Java project source package
- "Queue_Management_System_PPT-4.pptx" — Project presentation

How to Get Started

1. Download the project ZIP file from this repository.
2. Extract the ZIP file on your computer.
3. Open Eclipse IDE.
4. Import the project using the appropriate import option for its project structure.
5. Configure the required Java version and run the application.
